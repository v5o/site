# Music videos

Drop video files (`.mp4`, `.webm`, `.mov`, `.m4v`) in this folder. Each page
reload plays the next one in the list.

- The file name, without the extension, is the title in the tagline,
  e.g. `diegointhedark - 500pts.mp4` shows as `♪ diegointhedark - 500pts`.
- Optional: add an image with the same name (`.jpg`, `.png`, `.webp`) to use as
  the still frame shown while the video loads.
- To remove a video, delete its file. The list updates on the next deploy.

Tip: MP4 (H.264) under roughly 10 MB loads fastest on phones.
